# LetterQuest Ireland

A browser-based literacy learning prototype for **Junior Infants, Senior Infants, First Class and Second Class**.

## Features

- Multiple child profiles
- Beginner and Advanced modes within each class level
- Dinosaur, dragon, animal, ocean and fruit themes
- Letter-sound activities
- Blending and segmenting
- Word building and spelling activities
- “Sound it out” scaffolding using browser speech synthesis
- Parent progress dashboard
- Weekly school spelling list support
- Adaptive mastery scores
- Printable offline worksheet generator
- Local browser storage; no server required

## Irish curriculum direction

The learning progression is designed around Stage 1 and Stage 2 literacy concepts used in Irish primary education: phonological awareness, phonics/letter-sound relationships, blending, segmenting, word recognition, spelling and word study.

Before production or school adoption, curriculum sequencing, Gaeilge content, pronunciation recordings and pedagogical claims should be reviewed with qualified Irish primary teachers / literacy specialists.

## GitHub Pages

This is a static web app. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Privacy

The prototype stores profiles and progress in the browser’s `localStorage` and does not send them to a server. A production app for children should add parental consent, data minimisation, age-appropriate design and a formal GDPR/children’s privacy review.
